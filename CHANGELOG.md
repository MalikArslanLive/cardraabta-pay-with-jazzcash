# Changelog

## 1.0.0

- Hosted JazzCash checkout for WooCommerce Classic Checkout and Checkout Blocks, with separate Live and Sandbox credentials.
- Signed browser returns, signed IPNs and protected order-status links. The wallet waiting screen can reconcile a matching Live history result.
- Verified payment success, declines, pending status and duplicate-payment protection. Verified card type persists for the same payment reference.
- Merchant transaction history with pagination, search, status codes and eligible refund actions.
- Linked WooCommerce refunds, direct provider refunds and uncertain-outcome reconciliation.
- HPOS and legacy order storage, prepared transaction ledger queries and encrypted merchant secrets.
- Installable WordPress package, merchant and hosting guides, contributor instructions, and reproducible verification tools.
